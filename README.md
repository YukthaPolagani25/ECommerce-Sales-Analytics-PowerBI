# E-Commerce Sales, Customer & Product Analytics

## 📊 Project Overview
An interactive Power BI project analyzing e-commerce sales, customer behaviour, product performance, and order patterns.

## 🛠️ Tools Used
- Power BI Desktop
- Power Query
- DAX

## 📁 Dataset
- Customers
- Products
- Orders
- Order Items

## 📌 Key Analysis
- Sales performance and revenue trends
- Customer segmentation and retention
- Product and category performance
- Order status and payment methods
- Executive KPIs and business recommendations

## 📈 Dashboard Pages
1. Sales Performance
2. Customer Analytics
3. Product & Category Performance
4. Orders & Payment Behaviour
5. Customer Value & Retention
6. Executive Summary

## 🎯 Project Objective
To use data cleaning, modeling, DAX, and interactive visualizations to support data-driven business analysis.
